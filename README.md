# CheckAnyDesk

Плагин для **Purpur/Paper 1.21.4** (Java 21), который добавляет процедуру проверки игроков на читы через **AnyDesk**: модератор вызывает игрока, тот телепортируется в комнату проверки, а модератор подключается к нему через AnyDesk для осмотра.



## Возможности

- `/check <ник>` — начать проверку: телепорт в комнату, слепота, блокировка движения, взаимодействий, инвентаря и команд.
- `/check add <время>` / `/check remove <время>` — добавить/отнять время проверки (поддерживаются `s`, `m`, `h`, `d`).
- `/check stop` — успешно завершить проверку (игрок получает награду — Незер-звезду).
- `/check ban` — забанить проверяемого на 30 дней («Читы»).
- `/proverka set` — задать точку комнаты проверки.
- Чат проверяемого перенаправляется модератору.
- Автобан по кодовым словам/признанию с нечётким поиском:
  - транслитерация (русская ↔ английская раскладка),
  - замена цифр/символов (`4`, `@`, `!`, `$`…),
  - сглаживание повторных букв,
  - расстояние Левенштейна (≤1).
- Панель времени (BossBar), тайтлы, напоминания в чате каждые 10 секунд.
- Выход из игры или истечение времени → бан на 7 дней («Отказ от Проверки»).
- Переживание проверок между перезапусками (`active-checks.yml`).
- API-событие `CheckResultEvent` (`PASSED`, `CHEATS_BANNED`, `REFUSAL_BANNED`).

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/check` | Управление проверкой | `check.admin` (default: op) |
| `/proverka set` | Установить комнату проверки | `check.setup` (default: op) |
| — | Начать проверку из жалобы (ReportCenter) | `check.report` (default: false) |

## Сборка

```bash
mvn clean package
```

Собранный jar лежит в `target/CheckAnyDesk.jar`.

## Конфигурация

Все сообщения, длительность проверки, кодовые слова автобана и точка комнаты настраиваются в `config.yml` (генерируется автоматически при первом запуске). Цвета — через `&`.

## Лицензия

Неизвестна (исходный артефакт декомпилирован). Использование только с разрешения правообладателя.
